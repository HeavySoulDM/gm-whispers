# GM Whispers

ИИ-помощник ГМа для Foundry VTT (мир «Dungeons of Drakkenheim»):

- советник по приключению (готов к проверке, этап 1);
- тактика за монстров;
- итоги сессии;
- подсказки по ходу игры из голосового канала Discord.

**Статус:** этап 1, первая рабочая версия советника. План: [docs/PLAN.md](docs/PLAN.md).

**Тестовый мир:** `H:\Foundry_14\Data\worlds\dod-test`. Боевой мир `dod` не трогаем до этапа 6.

Документация: `CLAUDE.md` (вход для Claude в новом чате), `docs/ROADMAP.md` (план), `docs/ARCHITECTURE.md` (устройство), `docs/PLAN.md` (анализ и история).

## Первый запуск

1. **`server\setup.bat`** — создаёт окружение Python и ставит зависимости. Нужен Python 3.10+; если его нет, bat подскажет команду установки.
2. **`tools\link_module.bat`** — подключает модуль к Foundry ссылкой (один раз).
3. **`server\start.bat`** — запускает сервер с окном (в окне виден **локальный токен**). Или **`server\start_tray.bat`** — без окна, значком в трее у часов (правой кнопкой: папки данных и настроек, выход). Если хочешь, чтобы сервер стартовал вместе с Windows — `tools\autostart.bat` (отключить: `tools\autostart.bat off`); по умолчанию автозапуска нет.
4. В Foundry включи модуль **GM Whispers** в мире. Открой панель (**Alt+G** или шляпа волшебника на панели токенов) и нажми **⚙ «Настройки сервера»**: вставь локальный токен, нажми «Проверить связь», затем вставь ключ API (Claude или OpenAI — достаточно одного) и нажми «Проверить» рядом с ним: подтянется список моделей. **Сохранить**. Модели по умолчанию подбираются сами («авто»).
5. Нажми **«База»**, чтобы выгрузить журналы и компендиумы правил, и задай вопрос.

`server\check_setup.bat` — проверка окружения из командной строки (ключи, видеокарта); секреты не печатает.

## К игре

Перед сессией нажми **«К игре»** в панели: впиши пару строк о планах (необязательно), выбери, сколько последних итогов учесть, — через 1–2 минуты в папке журналов «GM Whispers · К игре» появится страница: где остановились, незакрытые нити, кто впереди, что пригодится из книги со ссылками, запасные варианты и чек-лист. Видна только мастеру.

## Библия кампании

Кнопка с книгой в панели. Первый раз — диалог: папка с квентами и сколько итогов учесть; через 1–3 минуты появится журнал «GM Whispers · Библия кампании» из двух страниц. **«Постоянное»** — твоя: партия и игроки, ключевые NPC, фракции, правила стола; модуль её не меняет, правь свободно. **«Текущее положение»** модуль переписывает после каждых «Итогов», в конце добавляя «Предложения в постоянное» — что стоит перенести наверх. Обе страницы уходят с каждым вопросом к модели, поэтому она не путает персонажей и знает, где партия сейчас.

## Итоги сессии и запись голоса

**Во время игры** модуль сам ведёт журнал сессии на сервере (`data/sessions/<дата_время>/events.jsonl`): чат и броски, начало и конец боя, раунды и ходы, изменения хитов, кто повержен, смена активной сцены, добыча героев. Чистка чата на журнал не влияет. Пишет только активный мастер; если сервер был выключен, события дождутся отправки. Отключается в настройках модуля («Вести журнал сессии»).

**Запись голоса (по желанию)** — Craig в Discord пишет каждого на отдельную дорожку.

*Через облако (удобнее всего):*
1. В [my.craig.chat](https://my.craig.chat) подключи облачную копию (Google Drive / Dropbox / OneDrive; тариф Supporter от $1). Формат — **FLAC, multi-track**. На тарифе с расшифровкой ($8) включи «Include transcription: WebVTT».
2. Поставь на ПК приложение этого облака, чтобы папка Craig синхронизировалась на диск, и впиши путь в `server\.env`: `GMW_CRAIG_INBOX=...`. Перезапусти `start.bat`.
3. После игры `/stop` → облако синхронизирует zip → в Foundry «Итоги»: окно покажет «Сначала забрать из Craig: …». Сервер возьмёт готовую расшифровку Craig (или распознает на видеокарте), привяжет к сессии по времени из `info.txt` и сразу составит итоги.
   Папку сервер сам не отслеживает; проверку раз в минуту включает `GMW_CRAIG_AUTO=1`.

*Вручную:* скачай **FLAC, multi-track** zip и перетащи на `server\transcribe.bat`. Есть расшифровка Craig в zip — берётся она; нет — распознаётся на видеокарте (один раз `server\setup_audio.bat`).

Заметки командой Craig `/note` во время игры попадают в шкалу времени как «Заметка ГМа». Кто есть кто — в `server\config\speakers.json` (`"heavy4soul": "Дима (ГМ)"`). Готовый текст (txt / srt / vtt) можно загрузить прямо в окне «Итоги».

**После игры:** панель → **«Итоги»** → выбрать сессию → по желанию заметки → «Составить итоги». Голос, чат и события Foundry сводятся на одну шкалу времени; результат — журнал в папке «GM Whispers · Дневник кампании» (видит только мастер), сразу в базе знаний советника.

## Структура

| Папка | Что там |
|---|---|
| `docs/` | План, решения, заметки по экспериментам |
| `foundry-module/gm-whispers/` | Модуль Foundry: панель советника, сбор контекста, выгрузка журналов |
| `server/` | GM Whispers Core: локальный сервер на Python (Claude API, база знаний) |
| `server/config/sources.json` | Как классифицировать журналы и какой у них приоритет |
| `tools/` | Служебные скрипты |
| `data/` | База знаний, логи расходов (`logs/usage.jsonl`), позже расшифровки. Не коммитится |

## Настройки сервера

Всё, что меняется от игры к игре, задаётся в Foundry: панель → **⚙ «Настройки сервера»** (или Настройки → Настройки модулей → GM Whispers → «Открыть настройки сервера»). Окно пишет в `server\.env` и `server\config\*.json`; перезапуск сервера не нужен.

- **Кампания** — название, система, мир, тон, особые правила, язык ответов: попадает во все запросы к модели. Заполнено для Драккенхейма; для другой кампании — перепиши.
- **Источники знаний** — вид каждой папки журналов (материалы мастера, дневник, приключение, мир, правила, не включать) и компендиумы галочками. При первом открытии подставлено то, что давали правила по названиям; после правок нажми «База».
- **Ключи API** — Claude, OpenAI, Gemini, DeepSeek, OpenRouter и «свой провайдер» (любой сервис с API, совместимым с OpenAI: RouterAI, локальные серверы — нужен адрес API). Достаточно одного. Хранятся только в `server\.env`; обратно сервер показывает лишь «задан …1234». Кнопка «Проверить» запрашивает у провайдера список моделей (бесплатно) — это и проверка ключа, и заполнение списков.
- **Модели по ролям** — «авто» подбирает по первому заданному ключу (порядок: Claude, OpenAI, Gemini, DeepSeek, OpenRouter, свой). Можно выбрать любую модель из списка и смешивать провайдеров. Для OpenAI — глубина размышлений.
- **Запись голоса** — папка, куда облако кладёт записи Craig; следить за ней самому или забирать по кнопке; модель распознавания.
- **Кто есть кто** — ник в Discord → подпись в расшифровке и дневнике. Новые участники появляются в списке после первой расшифровки.
- **Не учитывать** — дорожки ботов с музыкой (Kenku) и служебные авторы в чате («Подсказки» от AG D&D Hub).
- **Хранение и доступ** — старые сессии в архив через N дней (выключено по умолчанию); адреса Foundry, если он открыт не с localhost (хостинг).
- **Экспорт / Импорт** — настройки файлом без ключей и токена, например для второго компьютера.

Пока сервер, ключ или база не готовы, панель показывает три шага первого запуска. В строке статуса — расход за сегодня. Горячие клавиши (меняются в «Управлении»): Alt+G панель, Alt+T тактика для выделенного токена, Alt+R его реплика. После обновления модуля один раз показывается «Что нового».

Веса источников знаний (шпаргалки ГМа > книга > справочник > правила) — в `server\config\sources.json`.

### Через .env

То же самое можно задать в `server\.env` (образец — `.env.example`). Провайдер определяется по названию модели: `claude-…` идёт через Claude API (`ANTHROPIC_API_KEY`), `gpt-…` через OpenAI (`OPENAI_API_KEY`).

```
# По умолчанию
GMW_MODEL_LORE=auto
GMW_MODEL_TACTICS=auto
GMW_MODEL_FAST=auto

# Claude вручную
GMW_MODEL_LORE=claude-opus-5-5
GMW_MODEL_TACTICS=claude-sonnet-5-5
GMW_MODEL_FAST=claude-haiku-4-5-20251001

# OpenAI (запасной вариант)
GMW_MODEL_LORE=gpt-6.1-sol        # или gpt-6-astra, если ответы покажутся слабыми
GMW_MODEL_TACTICS=gpt-6.1-sol
GMW_MODEL_FAST=gpt-6-luna
GMW_OPENAI_REASONING=low          # low / medium / high: глубже = дольше и дороже
```

При правке `.env` руками перезапусти `start.bat`; из окна настроек всё применяется сразу.

**Контрольный набор:** `server\eval.bat` прогоняет 20 вопросов из `server\config\eval.json` и показывает, нашёл ли поиск нужные страницы (бесплатно, секунды); `eval.bat --llm` — полные ответы советника (платно). Запускай после смены модели или настроек. Вопросы замени на свои настоящие: `q` — вопрос, `expect` — часть названия страницы с ответом.

**Сборка в exe (для раздачи без Python):** `tools\build_exe.bat` → `server\dist\GM Whispers Core\` (PyInstaller, без faster-whisper — расшифровка в такой сборке берётся из готовой расшифровки Craig). Не проверялось вживую.

**Что уходит провайдеру модели:** текст журналов мира (в т. ч. скрытых от игроков), чат, расшифровка голоса, имена учёток игроков и персонажей. Ключи, токены и файлы мира — нет.
