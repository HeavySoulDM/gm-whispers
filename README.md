# GM Whispers — ИИ-помощник мастера для Foundry VTT

*English version: [README.en.md](README.en.md)*

Отвечает на вопросы по вашему приключению и миру со ссылками на страницы журналов, подсказывает тактику монстров по карте, пишет итоги сессии в дневник (в том числе по записи голоса из Discord), готовит сводку перед игрой. Работает только у мастера; игроки ничего не видят.

> Это первая версия для тестирования — будем рады обратной связи: https://github.com/HeavySoulDM/gm-whispers/issues

Состоит из двух частей: **модуль Foundry** (ставится как обычный модуль) и **GM Whispers Core** — небольшая программа на вашем компьютере, которая хранит базу знаний и ходит к ИИ-модели. Нужен ключ API одного из сервисов ИИ (Claude, OpenAI, Gemini, DeepSeek, OpenRouter или любой совместимый). Расход — обычно меньше доллара за игровой вечер.

## Установка за 10 минут

1. **Модуль.** Foundry → Дополнения → Установить модуль → вставьте ссылку на манифест (см. страницу релиза) → Установить. Включите модуль в мире.
2. **Core.** Распакуйте `GM_Whispers_Core` в любую папку (например, `C:\GM_Whispers_Core`) и запустите `server\setup.bat` один раз: он сам предложит поставить Python, если его нет, установит нужное и спросит, включать ли распознавание голоса (нужна видеокарта NVIDIA, скачает ~3 ГБ).
3. **Запуск.** `server\start.bat` — перед каждой игрой. В окне сервера показан **код доступа** (он же в `server\.env`).
4. **Мастер настройки.** Откройте мир — мастер первого запуска откроется сам и по шагам спросит код доступа, ключ сервиса ИИ, пару слов о кампании и что читать советнику. Потом его можно запустить снова из настроек (⚙ в панели → «Мастер настройки»).
5. **Готово.** База знаний и библия кампании соберутся сами (минута-две, ход виден в панели). Откройте панель (Alt+G или шляпа волшебника на панели токенов) и задайте первый вопрос.

Сервер запускается вручную перед игрой.

## Что умеет

- **Советник** — вопросы о мире, NPC, фракциях, правилах; ответ со ссылками `[1]` на страницы журналов. Ответ появляется по мере генерации.
- **Меню токена** — правый клик → шляпа: «Кто это и чего хочет», «Реплика», «Ход в бою». Горячие клавиши Alt+T (тактика) и Alt+R (реплика) для выделенного токена.
- **Тактика** — варианты хода с учётом расстояний, стен, укрытий, дверей и способностей (подробные статблоки — для D&D 5e).
- **К игре** — сводка перед сессией: где остановились, незакрытые нити, кто впереди, что пригодится из книги.
- **Итоги** — черновик итогов сессии по чату, событиям и голосу → журнал «Дневник кампании». Голос — запись ботом Craig в Discord: после игры скачайте архив из бота в указанную папку (лучший формат — многодорожечный FLAC; выгрузка в облако у Craig платная); распознаётся на вашей видеокарте (NVIDIA).
- **Библия кампании** — выжимка о партии, NPC и текущем положении, которую модель получает с каждым вопросом. «Постоянное» пишете вы, «Текущее» обновляется после итогов.
- **Настройки из Foundry** — ключи, модели, стиль ответов, язык, Craig, кто есть кто, хранение; экспорт/импорт.

## Стоимость и приватность

Модель оплачивается у сервиса ИИ по вашему ключу; расход за день виден в строке статуса панели. Сервису уходят тексты журналов мира (включая скрытые от игроков), чат, расшифровка голоса и имена персонажей и игроков. Ключи и файлы мира никуда не уходят: сервер слушает только ваш компьютер (127.0.0.1) и отвечает только вашему Foundry.

## Частые вопросы

**Нужна ли видеокарта?** Только для локального распознавания голоса. Без неё всё остальное работает; голос — через расшифровку Craig (платный тариф) или без голоса.

**Foundry открыт не с этого компьютера (хостинг)?** Core должен работать на компьютере мастера; адрес Foundry впишите в ⚙ → Подключение → Дополнительно → «Адреса Foundry на хостинге».

**Другая система, не D&D 5e?** Работает: советник, итоги, «К игре», библия, тактика по карте. Подробные статблоки монстров читаются только у dnd5e.

**Как обновлять?** Модуль — как обычный модуль Foundry. Core — скачать новый архив и распаковать поверх, `.env` и `data\` сохранятся.
