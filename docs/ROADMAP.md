## Решения (с 8.10; более ранние — PLAN.md §10)

- Модуль не запускает сервер — это ограничение Foundry; Core ставится отдельно, автозапуск с Windows только по желанию пользователя (`tools\autostart.bat`).
- Модели по умолчанию `auto` по заданному ключу; провайдер по названию модели.
- Сервер отвечает только localhost-страницам; хостинг Foundry — через `GMW_ALLOWED_ORIGINS`.
- Подсказки AG D&D Hub и боты (Kenku) не попадают в журнал и итоги; список в `ignore.json`.
- Архив старых сессий выключен по умолчанию.
- Это не финальный продукт: версии растут, «Что нового» ведётся в `changelog.js`, настройки добавляются полями без ломки старых `.env`.
