# GM Whispers — ИИ-помощник мастера для Foundry VTT

Отвечает на вопросы по вашему приключению и миру со ссылками на страницы журналов, подсказывает тактику монстров по карте, пишет итоги сессии в дневник (в том числе по записи голоса из Discord), готовит сводку перед игрой. Работает только у мастера; игроки ничего не видят.

Состоит из двух частей: **модуль Foundry** (ставится как обычный модуль) и **GM Whispers Core** — небольшая программа на вашем компьютере, которая хранит базу знаний и ходит к ИИ-модели. Нужен ключ API одного из провайдеров (Claude, OpenAI, Gemini, DeepSeek, OpenRouter или любой совместимый). Расход — обычно меньше доллара за игровой вечер.

## Установка за 10 минут

1. **Модуль.** Foundry → Дополнения → Установить модуль → вставьте ссылку на манифест (см. страницу релиза) → Установить. Включите модуль в мире.
2. **Core.** Распакуйте `GM_Whispers_Core` в любую папку (например, `C:\GM_Whispers_Core`). Нужен Python 3.10+ — если его нет, `server\setup.bat` подскажет команду установки. Запустите `server\setup.bat` один раз.
3. **Запуск.** `server\start.bat` — с окном, или `server\start_tray.bat` — без окна, значком в трее. В окне (или в `server\.env`) есть **локальный токен**.
4. **Связь.** В Foundry откройте панель (Alt+G или шляпа волшебника на панели токенов) → ⚙ «Настройки сервера» → вкладка «Подключение»: вставьте токен, нажмите «Проверить связь», вставьте ключ API и нажмите «Проверить» рядом с ним. Сохранить.
5. **Кампания.** Вкладка «Кампания»: название, система, пара предложений о мире и тоне. Вкладка «Источники»: отметьте, какие папки журналов что значат (материалы мастера / приключение / мир / правила / не включать).
6. **База.** В панели нажмите «База» — журналы уйдут в поиск (минута-две). Задайте первый вопрос.

Сервер запускается вручную перед игрой (по желанию — вместе с Windows: `tools\autostart.bat`).

## Что умеет

- **Советник** — вопросы о мире, NPC, фракциях, правилах; ответ со ссылками `[1]` на страницы журналов. Ответ появляется по мере генерации.
- **Меню токена** — правый клик → шляпа: «Кто это и чего хочет», «Реплика сейчас», «Ход в бою». Горячие клавиши Alt+T (тактика) и Alt+R (реплика) для выделенного токена.
- **Тактика** — варианты хода с учётом расстояний, стен, укрытий, дверей и способностей (подробные статблоки — для D&D 5e).
- **К игре** — сводка перед сессией: где остановились, незакрытые нити, кто впереди, что пригодится из книги.
- **Итоги** — черновик итогов сессии по чату, событиям и голосу → журнал «Дневник кампании». Голос — запись ботом Craig в Discord: облачная папка или перетащить zip на `server\transcribe.bat`; распознаётся на вашей видеокарте (NVIDIA) или берётся готовая расшифровка Craig.
- **Библия кампании** — выжимка о партии, NPC и текущем положении, которую модель получает с каждым вопросом. «Постоянное» пишете вы, «Текущее» обновляется после итогов.
- **Настройки из Foundry** — ключи, модели, стиль ответов, язык, Craig, кто есть кто, хранение; экспорт/импорт.

## Стоимость и приватность

Модель оплачивается у провайдера по вашему ключу; расход за день виден в строке статуса панели. Провайдеру уходят тексты журналов мира (включая скрытые от игроков), чат, расшифровка голоса и имена персонажей и игроков. Ключи и файлы мира никуда не уходят: сервер слушает только ваш компьютер (127.0.0.1) и отвечает только вашему Foundry.

## Частые вопросы

**Нужна ли видеокарта?** Только для локального распознавания голоса. Без неё всё остальное работает; голос — через расшифровку Craig (платный тариф) или без голоса.

**Foundry открыт не с этого компьютера (хостинг)?** Core должен работать на компьютере мастера; адрес Foundry впишите в ⚙ → Хранение → «Доп. адреса Foundry».

**Другая система, не D&D 5e?** Работает: советник, итоги, «К игре», библия, тактика по карте. Подробные статблоки монстров читаются только у dnd5e.

**Как обновлять?** Модуль — как обычный модуль Foundry. Core — скачать новый архив и распаковать поверх, `.env` и `data\` сохранятся.
